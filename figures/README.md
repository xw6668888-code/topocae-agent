# Author figures

This directory contains only the eight TIFF exports supplied by the author for the current manuscript. There is one Fig. 3 image (`fig3.tif`); alternate PNG/SVG/PDF training figures from older releases are excluded from the current tree.

Fig. 3 data are in `../data/training_curves/fig3_data.csv`. Display seeds 1, 2 and 3 correspond to numeric seeds 20260720, 20260719 and 20260718, respectively. Observed R history lengths are 56, 56 and 30 epochs in this order; Q lengths are 33, 56 and 56. The supplied Origin project contains all six histories. No missing epochs are extrapolated.

The 10 November export has a known plotting inconsistency: its lower-left Q panel appears to use the R/20260720 curve (56 epochs), while the corresponding Q history has 33 epochs. The lower row is labeled a/b/c rather than d/e/f. The author image is preserved as supplied; raw data are authoritative. See `../docs/MANUSCRIPT_ALIGNMENT.md` for all figure/caption corrections.
