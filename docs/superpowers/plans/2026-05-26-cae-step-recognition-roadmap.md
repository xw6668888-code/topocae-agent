```markdown
# Problem Scope

This project studies STEP/B-Rep graph recognition for single-part structural CAE preprocessing.

The input is a STEP model converted to an attributed adjacency graph where each node is a B-Rep face and each edge is face adjacency. The primary outputs are face-level feature classes, feature instances, idealization tags, and candidate CAE regions for boundary conditions, loads, and mesh refinement.

This work differs from machining feature recognition because its downstream target is CAE model preparation rather than process planning. Manufacturing-style features are kept when they help identify load-bearing, support, thin-wall, hole, slot, pocket, rib, boss, and transition regions.

Version 1 claims:

1. A CAE-oriented feature ontology for STEP/B-Rep face recognition.
2. A synthetic STEP/AAG dataset with face-level and instance-level labels.
3. A multi-task graph baseline for macro feature, semantic subtype, idealization tag, and instance grouping.
4. A downstream bridge from recognized feature objects to Abaqus face regions.

Version 1 does not claim fully automatic engineering-intent inference from arbitrary real parts. Real boundary and load semantics require analysis-case metadata.
```

- [ ] **Step 6: Report edge-affinity metrics**

Add a metric function using threshold 0.5:

```python
def compute_binary_f1(logits: torch.Tensor, targets: torch.Tensor) -> dict[str, float]:
    pred = (torch.sigmoid(logits.cpu()) >= 0.5).to(torch.int64)
    tgt = targets.cpu().to(torch.int64)
    tp = int(((pred == 1) & (tgt == 1)).sum().item())
    fp = int(((pred == 1) & (tgt == 0)).sum().item())
    fn = int(((pred == 0) & (tgt == 1)).sum().item())
    precision = _safe_divide(tp, tp + fp)
    recall = _safe_divide(tp, tp + fn)
    return {
        "precision": precision,
        "recall": recall,
        "f1": _safe_divide(2.0 * precision * recall, precision + recall),
    }
```

```python
def annotate_synthetic_analysis_roles(graph_data: dict, analysis_role_index: dict) -> dict:
    nodes = graph_data.get("nodes", [])
    key_to_id = analysis_role_index["key_to_id"]
    support_id = key_to_id["support_candidate_face"]
    load_id = key_to_id["load_candidate_face"]
    mesh_id = key_to_id["mesh_refinement_region"]

    stock_planar = [
        node for node in nodes
        if node.get("macro_feature") == "stock" and node.get("primitive_surface") == "plane"
    ]
    feature_faces = [
        node for node in nodes
        if int(node.get("macro_feature_id", 0)) > 0
    ]

    support_nodes = sorted(stock_planar, key=lambda n: n["attributes"]["physical"]["area"], reverse=True)[:1]
    load_nodes = sorted(feature_faces, key=lambda n: n["idx"])[:2]

    support_idx = {node["idx"] for node in support_nodes}
    load_idx = {node["idx"] for node in load_nodes}

    for node in nodes:
        ids = []
        keys = []
        if node["idx"] in support_idx:
            ids.append(support_id)
            keys.append("support_candidate_face")
        if node["idx"] in load_idx:
            ids.append(load_id)
            keys.append("load_candidate_face")
        if node.get("idealization_tags"):
            ids.append(mesh_id)
            keys.append("mesh_refinement_region")
        node["analysis_role_ids"] = ids
        node["analysis_roles"] = keys

    graph_data["analysis_case_summary"] = {
        "support_candidate_face_count": len(support_idx),
        "load_candidate_face_count": len(load_idx),
    }
    return graph_data
```
